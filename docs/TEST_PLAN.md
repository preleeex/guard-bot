# Тест-план

Краткая проверка guard mode и оплаты в тестовом окружении.

## Подготовка

1. Тестовый бот в @BotFather, поддержка join request queries включена.
2. Тестовая группа, бот добавлен админом с правом `can_invite_users`,
   включены «Заявки на вступление».
3. Бэкенд и Mini App задеплоены, webhook зарегистрирован.
4. Crypto Pay в режиме testnet (`CRYPTO_PAY_API_BASE=https://testnet-pay.crypt.bot/api`).

## A. Онбординг и подключение группы

1. Нажмите `/start` у бота новым аккаунтом.
   - Ожидание: ответ с кнопкой «Открыть панель»; в `SYSTEM_LOG_CHAT_ID` пришло
     событие «Новый пользователь».
2. Откройте панель, добавьте группу по @username, будучи её владельцем.
   - Ожидание: группа появилась в списке; событие «Группа подключена» в логе.
3. Попробуйте подключить ту же группу другим аккаунтом (не creator).
   - Ожидание: отказ «Подключить группу может только её владелец».

## B. Конструктор сценария и предпросмотр

1. В группе соберите сценарий: капча (математическая) + квиз (1 вопрос,
   проходной балл 100) + правила.
2. Запустите «Предпросмотр», пройдите верно.
   - Ожидание: результат «Одобрено».
3. Пройдите предпросмотр с неверным ответом капчи.
   - Ожидание: «Отклонено» (если включено авто-отклонение).
4. Сохраните сценарий, включите guard mode.

## C. Guard mode (query-режим)

1. С другого аккаунта подайте заявку на вступление в группу.
   - Ожидание: открывается Mini App со сценарием.
2. Пройдите успешно.
   - Ожидание: заявка одобрена, аккаунт в группе; в Журнале группы запись
     «Одобрено» с баллом и причиной. В чаты Telegram запись о заявке НЕ уходит.
3. Повторите с провалом и с порогом «очередь».
   - Ожидание: «Отклонено» либо «Очередь» согласно настройкам.

## D. Таймаут

1. Установите таймаут 60 секунд, действие «Отклонить».
2. Подайте заявку, не проходите Mini App.
   - Ожидание: примерно через минуту заявка отклонена, в Журнале запись
     «Таймаут».

## E. Legacy-режим (фолбэк)

1. На боте/в группе, где query-режим недоступен, подайте заявку.
   - Ожидание: бот присылает заявителю в ЛС кнопку «Пройти проверку»
     (если ЛС открыт). После прохождения заявка одобряется/отклоняется через
     `approveChatJoinRequest` / `declineChatJoinRequest`.

## F. Квота и оплата

1. Подключите 3 группы обычным владельцем.
   - Ожидание: попытка добавить 4-ю: отказ по лимиту.
2. Нажмите «Купить +3 группы».
   - Ожидание: открывается счёт Crypto Pay (testnet). Оплатите тестовыми
     средствами.
3. После оплаты дождитесь вебхука `invoice_paid`.
   - Ожидание: лимит увеличился на 3; в логе событие «Оплата»; теперь можно
     добавить ещё группы.

## G. Admin-режим (оператор)

1. Откройте Mini App под `OWNER_USER_ID = 7210276147`.
   - Ожидание: видна кнопка «Админ-панель», в ней общая статистика.
2. Выдайте слоты другому `user_id`.
   - Ожидание: у него вырос лимит; событие «Ручная выдача слотов» в логе.
3. Откройте Mini App под обычным пользователем.
   - Ожидание: кнопки «Админ-панель» нет; запрос к `/api/admin/*` -> 403.

## H. Безопасность

1. Запрос к API без валидного `X-Telegram-Init-Data`.
   - Ожидание: 401.
2. Запрос журнала чужой группы.
   - Ожидание: 403.
3. Попытка отправить ответы на чужую сессию скрининга.
   - Ожидание: 403.
